409B

Model 409B 170MHz 4-channel DDS signal generator. The 409B generates four independent, phase synchronous sine wave output signals and is programmable in 0.1Hz steps from 0.1Hz to 171MHz. Phase is 14-bit programmable and amplitude is 10-bit programmable.

Internal memory can store a sequence of settings in a table format. The -AC option is available to enable users to step through settings using an external trigger. It is accurate to 1.5ppm using the onboard TCXO timebase, or you can use an external timebase. There is also a /R option that provides a way to lock to and track an external 10MHz frequency input. A line-powered AC adapter and SOF8_409 Windows software are included.
